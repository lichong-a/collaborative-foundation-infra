# 代码、接口、数据与供应链

[返回入口](../SKILL.md)

命名表达业务用途，函数和模块保持单一职责；错误保留原因和安全上下文，不吞异常、不返回伪成功。对外部输入验证类型、范围、路径和权限，在可信业务边界执行不变量。

接口、事件、配置和持久化变化默认兼容。破坏性变化必须由任务明确批准，并提供调用方、迁移顺序、兼容窗口、回滚或前滚恢复。状态码、错误码、分页、幂等和取消语义清晰。

数据库通过约束维护一致性；事务短小，外部网络不进入长期持锁区。幂等写、事件重复/乱序、租户隔离、并发冲突和资源生命周期必须有失败路径。缓存与搜索是派生数据，明确失效、恢复和一致性窗口。

异步工作有限并发、超时、取消和重试上限；只重试可识别的瞬时错误。连接、文件、锁和临时目录使用可靠释放逻辑。日志结构化并脱敏；凭据和真实生产样本不进入代码、计划、测试快照或报告。

先读项目清单、锁文件、构建与代码生成脚本。优先标准库和已有依赖；新增依赖说明收益与许可证，使用锁文件，不顺手升级。生成代码必须通过对应生成器更新，业务项目不安装本治理工具的依赖。

安全性优先于照搬旧写法。只改批准范围，不全仓格式化、不删除失败测试、不通过白名单或关闭规则消除失败。
