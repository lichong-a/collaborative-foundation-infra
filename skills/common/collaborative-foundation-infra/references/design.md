# 设计模式与必要抽象

[返回入口](../SKILL.md)

先从真实变化点出发：什么行为稳定、什么需要替换、谁拥有状态和副作用。默认使用直接函数、组合和语言惯用接口；与不使用模式的基线比较后，再选择少量候选。

可读取 [ric-design-patterns-skill](../../../upstreams/ric-design-patterns/SKILL.md)，按语言索引定位一至三页。不要预加载 GoF 全部模式，也不要把分布式一致性、部署或权限问题强行套入 GoF。

Adapter 可用于已确认的第三方接口不兼容；Strategy 用于真实可替换算法；State 用于确有复杂合法迁移且持续变化的领域对象。一个分支、一个调用或未来也许复用都不足以引入框架。

决定记录在已有 Spec/Decision：基线、变化点、候选、代价、最小实现与验证。设计模式 Skill 不新增角色、Gate、批准权或状态机。教学示例不能自动视为并发安全或生产可用。

本工具将解析、政策、审计、快照、应用与外部分发分模块，用函数组合；没有另建工厂、事件总线或任务框架。
